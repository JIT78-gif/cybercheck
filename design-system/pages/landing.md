# Landing page overrides (`/`)

- Theme: **marketing (dark)** tokens.
- Section order: Nav → Hero (+ illustrative 4-tab report mock) → Why it matters → How it works (6 steps) → The four checks (alternating text / mock panel, LangSmith pattern) → Trust promises → Who it's for → FAQ → Final CTA → Footer.
- Copy rules: plain language a non-security person understands; every section answers "what is it, why should I care, what do I do next". No invented statistics, customers, testimonials or badges. Mock panels are labelled "Illustrative example".
- Primary CTA "Get started" → `/signup`; secondary "See how it works" → `#how-it-works`.
- FAQ uses native `<details>/<summary>` (keyboard + screen-reader friendly without JS).
