# App / dashboard overrides (`/app/**`, auth pages)

- Theme: **app (light)** tokens: warm off-white canvas, white cards, navy primary buttons (Tavily reference).
- Shell: fixed left sidebar ≥ 1024px (workspace switcher, nav with icon + label, user footer); collapsible drawer below 1024px. Breadcrumb header "Pages / <Section>".
- Data: mono font for IDs, revisions, digests, counts (tabular figures). Every percentage names its denominator.
- Status chips: icon + text + colour (Baselined = success, Validating = accent, Rejected = danger, Warning = warning).
- Auth pages: split layout with form left (max 400px), dark brand panel right (hidden < 1024px).
